이메일로 삭제 요청하기

메일 앱이 열리지 않으면 seraphiclady@naver.com으로 직접 보내 주세요. 버튼은 이메일 작성 화면을 열며, 직접 전송해야 요청이 접수됩니다.

현재 비공개 테스트 버전에는 회원가입·로그인이 없어 운영자가 보관하는 회원 계정이 없습니다. 지금도 문의 이메일에 포함된 개인정보의 삭제를 요청할 수 있습니다. 계정 기능 제공 후에는 아래 경로로 계정과 관련 데이터 삭제를 요청할 수 있도록 운영하며, 실제 수집 항목과 보관 기준은 기능 출시 전에 갱신합니다.

1. 요청 방법

  1. 제목을 네컷로그 계정 및 데이터 삭제 요청으로 작성합니다.
  2. 본문에 삭제할 대상(계정 전체 또는 기존 문의 정보)을 적어 주세요. 계정 기능을 이용한 경우 가입 이메일과 로그인 방법을, 기존 문의 삭제는 해당 문의 날짜나 제목을 적어 주세요.
  3. 가능하면 가입 또는 문의에 사용한 이메일에서 전송해 주세요. 접근할 수 없다면 그 사실을 알려 주세요. 필요한 최소한의 정보로 본인 확인 방법을 안내합니다.
  4. 운영자 toejji가 요청을 확인하고, 본인 확인 후 해당 데이터 삭제 및 처리 결과를 이메일로 안내합니다. 계정을 일시 정지하는 대신 계정과 관련 데이터를 삭제하는 요청입니다.

비밀번호, 인증번호, 신분증, 개인 사진은 보내지 마세요. 이 웹페이지는 입력 양식, 로그인, 분석·광고 스크립트를 사용하지 않습니다. 요청 내용은 공개 GitHub 저장소에 게시하지 않습니다.

2. 삭제 대상과 보관 기간

  • 현재 문의 정보: 운영자가 보관한 발신 이메일 주소, 문의 내용과 첨부 자료가 삭제 대상입니다. 본인 확인 및 요청 처리 완료 후 지체 없이 삭제하며, 별도의 추가 보관 기간을 두지 않습니다.
  • 계정 기능 출시 후: 운영자가 보관하는 해당 계정의 가입 이메일, 프로필, 소셜 로그인 연결 정보 등 계정 관련 데이터가 삭제 대상입니다. 실제 제공되지 않는 데이터 항목을 현재 수집한다는 의미는 아닙니다.
  • 법령상 보관 예외: 보관 의무가 적용되는 경우에만 해당 정보를 분리 보관하고, 요청자에게 대상 항목·근거·기간을 안내합니다. 현재 테스트 버전에는 운영자가 별도로 보관하는 결제·거래 기록이 없습니다. 새로운 보관 의무가 생기는 기능은 출시 전에 구체적인 항목과 기간을 공개합니다.

3. 기기에 저장된 사진과 앨범

사진과 앨범 데이터는 이용자 기기에 보관하며 운영자가 서버에 사본을 저장하지 않습니다. 이메일 요청으로 기기 데이터를 원격 삭제할 수 없습니다.

기기 데이터를 삭제하려면 Android의 설정 → 앱 → 네컷로그 → 저장공간 → 데이터 삭제를 이용하거나 앱을 제거하세요. 메뉴 이름은 기기마다 다를 수 있습니다. 필요한 자료는 먼저 직접 보관하세요. 삭제 후 운영자가 복구할 수 없습니다.

갤러리 원본과 이용자가 외부로 내보낸 파일은 별도로 삭제해야 합니다. 향후 계정 삭제 기능에서도 기기 내 자료 삭제 여부를 명확히 안내합니다.

4. 외부 서비스의 정보

네컷로그 계정 삭제는 Google·카카오·네이버 자체 계정 삭제를 뜻하지 않습니다. 광고 사업자가 독립적으로 처리하는 정보는 해당 서비스의 보관·삭제 정책도 적용됩니다. Google 개인정보처리방침을 참고하거나 문의 이메일로 안내를 요청해 주세요.
